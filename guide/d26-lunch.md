## [现场上层]{.lookup-name} {#site-upper data-lookup="工地上层 中间偏上 斗次郎 #2551 #2591 成人 CG 图库"}

中间偏上 · 斗次郎。**「偷偷去看」含成人画面，读完有地点奖 +8 GP。**

### ……不知从哪漏出下流的声音。怎么办……？ {#follow-the-sound}

::: {.choice-list data-place="现场上层"}
::: {#go-look-at-tojiro .choice-row data-lookup="偷偷过去看一眼 #2591 撞见斗次郎在工地的角落里打手枪"}
[偷偷去看]{.lookup-name} [−36 GP]{.gp-out}

撞见斗次郎并自动出现 CG，读完登记「[目击了在现场阴影处自慰的斗次郎](../collectibles/achievements.md#a2591){.achievement-ref}」，可在[图库回放](../collectibles/gallery.md#replay-d26-upper-site){.gallery-ref}，也计入斗次郎的标题立绘。继续读到收尾领地点奖。
:::

::: {#leave-site-upper .choice-row data-lookup="离开这里"}
[离开]{.lookup-name} [+4 GP]{.gp-in}

离开上层并回地图，可再挑一个地点。这项只结算选项 GP。
:::
:::

## [现场下层]{.lookup-name} {#site-lower data-lookup="工地下层 偏右下 熊手 斗次郎 集体生活 #2552"}

偏右下 · 熊手 · 地点奖 **+8 GP**

熊手在下层休息，和主角聊社宅集体生活以及斗次郎与文治的关系。一路读完即可登记。

## [值班室]{.lookup-name} {#guardroom data-lookup="工棚 左下 笹吉 兽迷 两道问答 #2553"}

左下 · 笹吉 · 地点奖 **+8 GP**

### 和兽人做下流的事，想吧？ {#sasakichi-teases}

::: {.choice-list data-place="值班室"}
::: {#admit-interest .choice-row data-lookup="想做"}
[想]{.lookup-name} [+6 GP]{.gp-in}

笹吉顺着回答，鼓动主角主动一点。
:::

::: {#deny-interest .choice-row data-lookup="不想做"}
[不想]{.lookup-name} [+4 GP]{.gp-in}

笹吉不信，继续开玩笑。两项都会接到下一问。
:::
:::

### 或者真做过，有吧～？ {#sasakichi-asks-about-experience}

::: {.choice-list data-place="值班室"}
::: {#admit-experience .choice-row data-lookup="有过"}
[有]{.lookup-name} [+6 GP]{.gp-in}

笹吉说有这样的想象或经验很正常。
:::

::: {#deny-experience .choice-row data-lookup=""}
[没有]{.lookup-name} [+4 GP]{.gp-in}

笹吉继续开玩笑。两道题都只改对白，读完任一走法都能领地点奖。

:::

## [事务所]{.lookup-name} {#office data-lookup="办公室 左侧靠边 监督 北野门左卫门 北之门 烤肉 便当 #2554"}

左侧靠边 · 监督、北野门左卫门 · 地点奖 **+8 GP**

撞见北野门左卫门在找监督。之后聊到上次的烤肉便当和兽人的口味，读完即可登记地点。

## [厕所]{.lookup-name} {#restroom data-lookup="左下偏中 文治 饮料 #2555 #2592 成人 CG 图库"}

左下偏中 · 文治 · 地点奖 **+8 GP**

文治提议请喝饮料。**「再让他给看一次」含未经同意的接触及成人 CG。**

### 那请你喝饮料，喝了忘掉。 {#bunji-offers-a-drink}

::: {.choice-list data-place="厕所"}
::: {#take-the-drink .choice-row data-lookup="让他请喝饮料"}
[让他请客饮料]{.lookup-name} [+4 GP]{.gp-in}

一起去买饮料，继续聊刚才的事。读到结束领地点奖。
:::

::: {#ask-bunji-to-show-again .choice-row data-lookup="让文治把性器露给自己看 #2592 在厕所前让文治射在了脸上"}
[再让他给看一次]{.lookup-name} [−40 GP]{.gp-out}

进入成人场景。读完登记「[在厕所前让文治颜射](../collectibles/achievements.md#a2592){.achievement-ref}」，开放[图库回放](../collectibles/gallery.md#replay-d26-restroom){.gallery-ref}，也计入文治的标题立绘。之后仍有地点奖。
:::
:::

## [大门前]{.lookup-name} {#gate data-lookup="最右侧 狸丸 台风 寿命 兽心 #2556 狸丸的秘密 番外"}

最右侧 · 狸丸 · 在场时读完领 **+8 GP**

::: {#tanukimaru-visit .event-record data-lookup="#2556 狸丸的秘密 番外 拜访 D24 D27"}
[狸丸谈生命的意义]{.lookup-name}

狸丸还在工地时，会自动聊到台风吹走房子，以及兽心和活着的意义。读完登记 **#2556**，计入「狸丸的秘密」。相邻两次指定拜访在 [D24 大门前](d24-lunch.md#gate)和 [D27 大门前](d27-lunch.md#gate)。
:::

狸丸已消失时，大门前显示没人并返回地图，本次没有拜访记录或地点奖。

## [材料存放处]{.lookup-name} {#materials data-lookup="材料堆放处 右下 空地点 没人 #2557 0 GP"}

右下 · 没人 · **0 GP**

读到没人就返回地图。依然登记地点完成度 **#2557**，可以再选其他地点。

## 选完后怎么补 {#revisit}

- 普通午休读完一处剧情就接下午工作。现场上层选「离开」、材料存放处没人、狸丸已消失时的大门前，都会让你回到地图再选。
- 用时间线的[「从午休开始」](../mechanics/timeline.md#back-to-d26)回补。解锁[「无限午休功能」](../mechanics/gp.md#features)后可在同一轮逛多个地点。狸丸在时地点奖合计 **+48 GP**，他已消失时合计 **+40 GP**。要拿现场上层的地点奖，需要读完 36 GP 分支。看完点「午休结束」。
