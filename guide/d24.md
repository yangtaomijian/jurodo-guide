## [起床]{.lookup-name} {#wakeup data-lookup="从起床开始 熊手 台风 狸丸 早上"}

时间线选「从起床开始」。熊手一早才回社宅，主角决定要不要让他继续睡。

### 要叫醒熊手吗 {#let-kumade-sleep}

::: {.choice-list data-place="起床 · 社宅"}
::: {#let-kumade-rest .choice-row data-lookup="让他继续睡"}
[轻轻让他睡]{.lookup-name} [+4 GP]{.gp-in}

让熊手多睡一会儿。
:::

::: {#kick-kumade-awake .choice-row data-lookup="踹醒他"}
[踢醒]{.lookup-name} [+6 GP]{.gp-in}

主角踢醒熊手，文治斥责主角。两项都继续出门。
:::
:::

关闭「剧情缩短」且狸丸还在时，到工地会自动听到他提醒台风夜小心。这段是上工前的对白。番外拜访的登记点在[自由午休的大门](d24-lunch.md#gate)。

## [朝礼]{.lookup-name} {#morning-meeting data-lookup="朝会 晨会 台风 停工 安全"}

监督宣布明天停工，并提醒收工前固定好会被吹走的材料。狸丸还在时也会参加朝礼。「剧情缩短」会略过朝礼。

## [上午]{.lookup-name} {#morning data-lookup="从上午工作开始 从上午作业开始 扶手 隔墙 拆模 CG"}

「从上午工作开始」进入施工。下面三问和隔墙拆模插图都在完整的上午段，回补前关闭「剧情缩短」。

### ……你是认真在嘲我吧。 {#tease-tojiro}

::: {.choice-list data-place="上午 · 拆扶手"}
::: {#admit-teasing .choice-row data-lookup="确实小看你了"}

斗次郎说以后什么也不教，主角赶紧说是在开玩笑。
:::

::: {#deny-teasing .choice-row data-lookup="没有小看你"}

否认小看斗次郎。之后同样去固定钢管。
:::
:::

### 小兄弟也热坏了吧。在这歇会儿？ {#take-a-break}

::: {.choice-list data-place="上午 · 拿链条"}

[歇一会儿]{.lookup-name} [+4 GP]{.gp-in}

留下来和北野门左卫门、熊手聊一阵。
:::

::: {#keep-working .choice-row data-lookup="没时间休息"}

继续去取链条。熊手称赞主角能干，两项都会接着施工。
:::
:::

::: {.choice-list data-place="上午 · 拆隔墙"}

## [午休前]{.lookup-name} {#before-lunch data-lookup="烤肉 便当 监督 人类用 兽人用"}

监督带来烤肉便当。要补便当问答，从「从上午工作开始」读下来。

### 尝尝这边的肉。好吃！ {#beastfolk-bento}

::: {.choice-list data-place="午休前 · 值班室"}
::: {#accept-beastfolk-meat .choice-row data-lookup="吃"}
[我吃]{.lookup-name} [+4 GP]{.gp-in}

主角想尝，监督出声劝阻。
:::

::: {#decline-beastfolk-meat .choice-row data-lookup=""}
[拒绝]{.lookup-name} [+6 GP]{.gp-in}

主角婉拒。两项都继续吃监督备给人类的那份，之后进入自由午休。
:::
:::

## [午休]{.lookup-name} {#lunch data-lookup="从午休开始 自由午休 #2356 狸丸的秘密 现场上层 值班室"}

[打开 D24 午休地图](d24-lunch.md)。时间线选「从午休开始」会跳过便当段，直接进入地图。

- **现场上层**花 **8 GP** 听鹞鹰谈文治，收一项成就。
- **值班室**有 **40 GP** 的成人 CG、成就和图库。
- **大门前**趁狸丸在时读完对话，领 **+8 GP**，同时计入「狸丸的秘密」。

## [下午]{.lookup-name} {#afternoon data-lookup="从下午工作开始 从下午作业开始 台风防护 拆模板"}

时间线选「从下午工作开始」。大家一起拆完模板，监督来检查台风防护。随后回值班室收工。

### 这次没肌肉痛？ {#muscle-soreness}

::: {.choice-list data-place="收工 · 值班室"}
::: {#say-fine .choice-row data-lookup=""}

::: {#admit-soreness .choice-row data-lookup="照样肌肉酸痛"}

风已经起来。出工地时，狸丸还在就会再提醒主角小心。这段同样是自动对白。

## [回家]{.lookup-name} {#home data-lookup="从回家开始 台风 防护 干粮 麦片 停电 雷声 文治 #2393"}

从「从回家开始」读下去。大家先给社宅做防护，晚饭自动出现麦片插图。停电后有固定的怪谈和惊吓音效，继续到文治被雷声吓到才出现下题。
