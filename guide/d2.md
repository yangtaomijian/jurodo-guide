## [起床]{.lookup-name} {#wakeup data-lookup="斗次郎 文治 熊手 朝会 朝礼 指差呼称 早餐 从起床开始"}

时间线选「从起床开始」。

斗次郎来催主角准备，大家出门上工。完整剧情会经过便利店和工地值班室的早餐，接着参加朝会。文治带主角做「指差呼称」，熊手安排主角帮忙卸料。开启「剧情缩短」会跳过一部分出勤对白。

## [上午]{.lookup-name} {#morning data-lookup="从上午工作开始 从上午作业开始"}

时间线选「从上午工作开始」，会经过上午作业和下面两组午休前问答。

### 雪之丞打招呼 {#yukinojo}

主角在等运材料的卡车时见到雪之丞。

::: {.choice-list data-place="上午"}
::: {#greet-yukinojo .choice-row data-lookup="雪之丞 问候 请多指教"}
[请多关照]{.lookup-name} [+4 GP]{.gp-in}

正常回应招呼，随后一起卸料。
:::

::: {#pull-tail .choice-row data-lookup="雪之丞 拽尾巴 拽住尾巴"}
[拉尾巴]{.lookup-name} [+4 GP]{.gp-in}

雪之丞被拽疼，主角道歉后照常开工。
:::

::: {#touch-yukinojo .choice-row data-lookup="雪之丞 摸摸胯下 与雪之丞互相触摸了股间 与雪之丞互相抚摸了裆部 #191"}
[摸裆]{.lookup-name} [−12 GP]{.gp-out}

两人有额外的肢体接触，登记成就「[与雪之丞互相触摸了股间](../collectibles/achievements.md#a191){.achievement-ref}」。之后照常卸料。
:::
:::

::: {#unloading .event-record data-lookup="雪之丞 垫木 模板 卡车 吊车 插图 CG"}
[卸料插图]{.lookup-name}

打完招呼，雪之丞操作卡车吊机，主角帮忙放垫木、稳住模板。三张卸料画面随剧情依次出现。
:::

### 午休前买便当 {#before-lunch}

斗次郎问「为了我们什么都会干吧？」

::: {.choice-list data-place="午休前"}
::: {#run-errand .choice-row data-lookup="斗次郎 便当 买饭 什么都愿意做"}
[什么都干]{.lookup-name} [+4 GP]{.gp-in}

主角独自去便利店买便当，回来后接午饭。
:::

::: {#refuse-errand .choice-row data-lookup="斗次郎 什么都不做 便当 买饭"}
[不是什么都干]{.lookup-name} [+4 GP]{.gp-in}

熊手让斗次郎去买，斗次郎叫主角同行。路上会出现[下一组问答](#on-the-way)。
:::

::: {#kick-tojiro .choice-row data-lookup="斗次郎 一脚踹向斗次郎的胯下 向上踢了斗次郎的股间 狠狠踹了斗次郎的裆部 #192"}
[踢斗次郎的裆]{.lookup-name} [−16 GP]{.gp-out}

登记成就「[向上踢了斗次郎的股间](../collectibles/achievements.md#a192){.achievement-ref}」。斗次郎去不了，主角替他买便当，回来后接午饭。
:::
:::

### 跟斗次郎去便利店 {#on-the-way}

上一问选「不是什么都干」才出现。游戏提示「……要不要说点什么。」

::: {.choice-list data-place="去便利店途中"}
::: {#apologize .choice-row data-lookup="斗次郎 道歉"}
[为拒绝跑腿道歉]{.lookup-name} [+4 GP]{.gp-in}

斗次郎训了主角几句，之后继续去便利店。
:::

::: {#ask-anger .choice-row data-lookup="斗次郎 怒 生气 问他是否在生气"}
[问他生不生气]{.lookup-name} [+4 GP]{.gp-in}

斗次郎揪住主角的衣领并威胁他。两人随后照常去买饭。
:::

::: {#ask-size .choice-row data-lookup="斗次郎 尺寸 询问对方性器的尺寸"}
[问性器尺寸]{.lookup-name} [−8 GP]{.gp-out}

斗次郎先骂主角，之后反问并炫耀。两人随后照常去买饭。
:::
:::

## 午休 {#lunch}

买完便当后各支汇合，午饭过后进入自由行动。时间线选「从午休开始」可直达地图。

[打开 D2 午休地图指南](d2-lunch.md)，可查八处地点、五个选项、GP 和回补方法。要补狸丸的前置，可直接查[大门前](d2-lunch.md#gate)。

## [下午与收工]{.lookup-name} {#afternoon data-lookup="从下午工作开始 从下午作业开始"}

时间线选「从下午工作开始」，会走到收工后去超市的问答。

::: {#lifting .event-record data-lookup="文治 垫木 立柱 扶手 吊运 插图 CG"}
[递垫木插图]{.lookup-name}

主角把立柱搬上二楼，再从下方递垫木给文治。这组插图在对话里自动播放。开启「剧情缩短」仍能看到这组画面，后面的搬运扶手一段会被跳过。
:::

### 超市找东西 {#shopping}

收工后主角请大家在超市停一下。文治问「……在找什么？」

::: {.choice-list data-place="超市"}
::: {#find-beef .choice-row data-lookup="文治 牛肉 买菜 我在找牛肉"}
[在找牛肉]{.lookup-name} [+4 GP]{.gp-in}

直接请文治帮忙找牛肉。买齐后回社宅。
:::

::: {#find-condoms .choice-row data-lookup="文治 安全套 保险套 我在找避孕套"}
[在找安全套]{.lookup-name} [−4 GP]{.gp-out}

多一段关于安全套的对白，随后还是由文治帮忙找到牛肉。
:::
:::

## [回家]{.lookup-name} {#home data-lookup="从回家开始"}

时间线选「从回家开始」。主角做了牛丼，上桌和开饭时会看到餐食插图，随后熊手才问明天起能否把晚饭交给主角。

::: {.choice-list data-place="回家"}
::: {#accept-dinner .choice-row data-lookup="熊手 牛丼 做饭 晚饭 负责晚饭"}
[答应]{.lookup-name} [+4 GP]{.gp-in}

主角当场接下晚饭，大家吃完了牛丼。
:::

::: {#decline-dinner .choice-row data-lookup="熊手 牛丼 做饭 晚饭 负责晚饭"}
[拒绝]{.lookup-name} [+6 GP]{.gp-in}

主角先推辞，文治和熊手再开口请他做饭，他最终答应。两项都接到晚饭后的剧情。
:::
:::

::: {#late-night .event-record data-lookup="斗次郎 厕所 夜里 夜间 起夜 浴室 更衣室 剧情缩短"}
[洗澡和夜里碰见斗次郎]{.lookup-name}

主角准备洗澡时，斗次郎在更衣室过来谈晚饭。主角入睡后，完整剧情还会播放起夜时碰见斗次郎的对话。开启「剧情缩短」会跳过起夜段。
:::

### [当天结算]{.lookup-name} {#day-reward data-lookup="首次推进奖励 GP 作为读物的故事 作为性处理的工具"}

第一次推进到 D2 收尾时，「作为读物的故事」档得 **+12 GP**，「作为性处理的工具」档得 **+25 GP**，「作为游戏的娱乐」档无这笔奖励。两种晚饭回答都能推进到结算，重走 D2 不会再发这笔奖励。
