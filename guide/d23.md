时间线选「从起床开始」。到加工场发现暂时没活，斑提出改为打扫厕所。

### 今天没工钱，也行？ {#work-without-pay}

::: {.choice-list data-place="起床 · 加工场"}
::: {#accept-no-pay .choice-row data-lookup="没关系"}
[可以]{.lookup-name} [+4 GP]{.gp-in}

主角同意走人，斗次郎也附议。文治最后仍决定接清洁工作。
:::

::: {#refuse-no-pay .choice-row data-lookup="不要"}
[不行]{.lookup-name} [+4 GP]{.gp-in}

主角说想保住当天工钱，斗次郎仍不愿扫厕所。文治接下活，三人去打扫。
:::
:::

## [午休]{.lookup-name} {#lunch data-lookup="固定午休 台风 加工场 电视 斗次郎"}

大家在加工场看天气预报。时间线从上午工作开始，清扫后会来到这段。

「从下午工作开始」进入面谈。三问依次出现，各自结算选项 GP，六个回答都能继续。

::: {#not-used-to-job .choice-row data-lookup="还没适应"}

## [收工]{.lookup-name} {#work-end data-lookup="兽神祭 #2291 3P 聊天 说工作 说公司 说色的"}

社长面谈后，三人聊起即将到来的兽神祭。要重选这一题，用「从下午工作开始」读过面谈。

### 斗次郎问还有什么可聊 {#after-work-topic}

::: {.choice-list data-place="收工 · 闲聊"}
::: {#talk-about-work .choice-row data-lookup="聊聊工作的事 #2291 丢弃了"}
[说工作]{.lookup-name} [+4 GP]{.gp-in}

聊工作。已有「[向文治和斗次郎提议了3P](../collectibles/achievements.md#a2291){.achievement-ref}」时会提示「丢弃了」，今晚便绕过对应场景。
:::

::: {#talk-about-company .choice-row data-lookup="聊聊公司的事 #2291 丢弃了"}
[说公司]{.lookup-name} [+4 GP]{.gp-in}

聊公司，也会丢弃已持有的「[向文治和斗次郎提议了3P](../collectibles/achievements.md#a2291){.achievement-ref}」。
:::

::: {#suggest-three-person-scene .choice-row data-lookup="聊聊色色的话题 #2291 向文治和斗次郎提议进行 3P"}
[说色的]{.lookup-name} [−80 GP]{.gp-out}

登记「[向文治和斗次郎提议了3P](../collectibles/achievements.md#a2291){.achievement-ref}」。之后读到[晚饭后](#living-room-scene)，会自动进入含成人 CG 的场景。已解锁此选项时，可回来重选并恢复前置。
:::
:::

[味噌]{.lookup-name} [+4 GP]{.gp-in}

文治觉得主角和自己合拍，拿这事跟斗次郎争输赢。

::: {#prefer-salt-ramen .choice-row data-lookup="盐味"}
