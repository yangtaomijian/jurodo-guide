时间线选「从午休开始」。有人地点各给 **+8 GP**，读到收尾到账，和选项的 GP 分开算。

## [现场下层]{.lookup-name} {#site-lower data-lookup="工地下层 斗次郎 文治 争执 #1191 CG 图库"}

偏右下 · 斗次郎 · 地点奖 **+8 GP**

**「贬低斗次郎」含强迫情节。**

### 斗次郎抱怨文治 {#tojiro-argument}

::: {.choice-list data-place="现场下层"}
::: {#reason-with-tojiro .choice-row data-lookup="劝说斗次郎"}
[说服斗次郎]{.lookup-name} [+4 GP]{.gp-in}

主角劝两人互相帮忙。斗次郎拒绝，主角离开，读完领地点奖。
:::

::: {#belittle-tojiro .choice-row data-lookup="#1191 在工地现场被斗次郎骑乘了 在工地被斗次郎骑乘压制了"}
[贬低斗次郎]{.lookup-name} [−24 GP]{.gp-out}

激怒斗次郎，进入付费场景并出现 CG。读到成就「[在现场被斗次郎骑乘](../collectibles/achievements.md#a1191){.achievement-ref}」登记可解锁[图库回放](../collectibles/gallery.md#replay-d12-tojiro){.gallery-ref}，读到收尾再领地点奖。
:::
:::

## [事务所]{.lookup-name} {#office data-lookup="办公室 左侧 监督 兽心 文治 斗次郎"}

左侧靠边 · 监督 · 地点奖 **+8 GP**

### 监督问你能不能接受和文治或斗次郎亲近 {#supervisors-suggestion data-lookup="接触他们不抗拒，做不到吗？ ……我以为你是兽迷，接触他们不抗拒，做不到吗？ ……我还以为既然是兽人控，对和他们接触就不会有什么抗拒呢，难道您接受不了吗？"}

::: {.choice-list data-place="事务所"}
::: {#can-get-close-to-both .choice-row data-lookup="能和文治或斗次郎做爱"}
[能和文治、斗次郎发生关系]{.lookup-name} [+6 GP]{.gp-in}

监督进一步解释他的建议。主角表示会考虑，之后离开事务所。
:::

::: {#cannot-get-close-to-both .choice-row data-lookup="无法和他们两人做爱"}
[不能和那两人发生关系]{.lookup-name} [+4 GP]{.gp-in}

主角说做不到，监督改提让文治和斗次郎多亲近。两项都只改对白，读完领地点奖。
:::
:::

## [大门前]{.lookup-name} {#gate data-lookup="最右侧 狸丸 狸丸的秘密 #1156 番外前置 调解"}

最右侧 · 狸丸

::: {.event-record}
狸丸在场时，主角问他怎么处理文治和斗次郎的争吵。读完自动登记「狸丸的秘密」的一项前置，并得 **+8 GP**。如果狸丸已经离开，点这里会看到空地点，0 GP，随后回地图。
:::

## 选完后怎么补 {#revisit}

- 有人地点读完会接下午工作，空地点会回地图。离开后可从[时间线的「从午休开始」](../mechanics/timeline.md#back-to-d12)回补。
- 解锁[「无限午休功能」](../mechanics/gp.md#features)后，读完可回地图继续选，结束时点右侧箭头。已登记的成就和图库回放会保留。
