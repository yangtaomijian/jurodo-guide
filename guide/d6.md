## [起床与出勤]{.lookup-name} {#wakeup data-lookup="从起床开始 值班室 朝会 晨会"}

时间线选「从起床开始」。到工地后，文治在值班室睡着了。两项都能叫醒他，接着参加朝会。

### 文治先生还在睡……要叫醒吗？ {#wake-bunji}

::: {.choice-list data-place="出勤 · 值班室"}
::: {#wake-gently .choice-row data-lookup="温柔地叫醒他 文治 朝会"}
[温柔叫醒]{.lookup-name} [+4 GP]{.gp-in}

叫文治起来参加朝会。
:::

::: {#wake-achievement .choice-row data-lookup="揉着他的胯下叫醒他 揉捏文治的裆部，让他有了晨勃 揉了文治的股间让他晨勃 #591"}
[揉胯下叫醒]{.lookup-name} [−8 GP]{.gp-out}

这段剧情会登记成就「[揉了文治的股间让他晨勃](../collectibles/achievements.md#a591){.achievement-ref}」，随后接朝会。

## [上午]{.lookup-name} {#morning data-lookup="从上午工作开始 从上午作业开始 土间留 手扶 支模"}

时间线选「从上午工作开始」。关闭「剧情缩短」才能看到这段的施工插图和文治问答。

::: {#work-illustrations .event-record data-lookup="吊运 钢筋 土间留 型框 手扶 支撑 阳台 插图 CG"}
[吊运和支模插图]{.lookup-name}

上午先有吊运钢筋、递「土间留」的画面，随后出现安装手扶型框的图。问答结束后还有加固型框和装支撑的图。这些画面随施工自动出现。
:::

### 去帮文治 {#help-bunji}

斗次郎让主角过去搭把手，两项最后都回斗次郎那边。

::: {.choice-list data-place="上午工作"}
::: {#talk-to-bunji .choice-row data-lookup="和文治搭话 文治 斗次郎"}
[跟文治说话]{.lookup-name} [+4 GP]{.gp-in}

文治说自己暂时脱不开手，让主角回去帮斗次郎。
:::

::: {#startle-bunji .choice-row data-lookup="从背后揍他 文治 斗次郎"}
[从后面打]{.lookup-name} [+6 GP]{.gp-in}

文治吃痛，和主角争执几句，随后也让他回斗次郎那边。

:::

时间线选「从工作结束开始」会从这顿午饭播起。午饭随剧情推进，没有自由行动地图。熊手交代周一的工作后，斗次郎要文治复述。

### 周一的工作安排是什么？ {#monday-work data-lookup="大将说了什么，你说说。 有种把头儿刚才说的复述一遍啊。"}

## [收工]{.lookup-name} {#work-end data-lookup="从工作结束开始 从作业结束开始 早收工 超市 猫罐头"}

午饭后就收工。熊手和其他人分开走，主角跟文治、斗次郎回去，途中到超市。

[不行]{.lookup-name} [+6 GP]{.gp-in}

::: {#allow-cat-food .choice-row data-lookup="没关系 斗次郎 猫罐头"}

## [回家]{.lookup-name} {#home data-lookup="从回家开始 晚饭 拉面 社宅 游戏"}

时间线选「从回家开始」。

::: {#minigame .event-record data-lookup="便便跳跃・改便 便便跳跃改便 结束便便跳跃改便 小游戏"}
[便便跳跃・改便]{.lookup-name}

文治把游戏交给主角后会自动进入小游戏。想继续当天剧情，在小游戏菜单选「结束便便跳跃改便」即可。主线走向和成绩无关，时间线另有两项成就可领。

- [极致游戏之人](../collectibles/achievements.md#a4521){.achievement-ref #master-the-minigame .lookup-name data-lookup="游戏精通者 困难模式 便便跳跃改便"}。第一次打败第 100 波的便便，「STORE」会开放「困难模式」。退出小游戏后，打开时间线即可领成就。
- [制霸游戏之人](../collectibles/achievements.md#a4522){.achievement-ref #conquer-the-minigame .lookup-name data-lookup="游戏制霸者 困难模式 便便跳跃改便"}。在「STORE」用小游戏里的 **100,000 分**买下「困难模式」，再到「CUSTOMIZE」装备。首次进入困难模式从第 1 波开始。打败困难模式第 100 波的便便后，退出小游戏并打开时间线领成就。
:::

:::
