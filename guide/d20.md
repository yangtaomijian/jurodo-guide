## [起床]{.lookup-name} {#wakeup data-lookup="从起床开始 营地 下山 加工场 宿醉"}

时间线选「从起床开始」。众人收帐篷下山，回社宅放行李，再去加工场。文治宿醉和斑问起露营是固定对白，D19 同寝三条路线都接这里。

## [上午]{.lookup-name} {#morning data-lookup="从上午工作开始 从上午作业开始 雪之丞 露营 模板"}

时间线选「从上午工作开始」。雪之丞会在加工场问起昨晚的露营。

### 听说你们昨天撞得砰砰响来着！ {#camping-rumor}

::: {.choice-list data-place="上午 · 加工场"}
::: {#deny-camping-rumor .choice-row data-lookup=""}
[什么都没做]{.lookup-name} [+4 GP]{.gp-in}

雪之丞说是听斑提起的，文治嫌话传得走样。
:::

::: {#play-along-with-rumor .choice-row data-lookup="狠狠大做特做了一番"}
[猛干了一晚上]{.lookup-name} [−4 GP]{.gp-out}

主角顺着话开玩笑，雪之丞起哄，文治随后否认。两项都继续加工。
:::
:::

### [午休前]{.lookup-name} {#before-lunch data-lookup="吃便当 电视 新闻 人工子宫 兽人的孩子 D35 #1991"}

吃便当时，电视播到人工子宫的新闻。要补这道题，从「从上午工作开始」读到这里。

### 值不值得为了有个自己的孩子做移植？ {#children-question data-lookup="至于那么想要自己的小鬼？ 至于非得这样要个自己的小崽子吗？"}

::: {.choice-list data-place="午休前 · 休息处"}
::: {#want-beastfolk-child .choice-row data-lookup="#1991 D35 人工子宫移植 生育前置 梦想着与兽人生下孩子的未来"}
[我也想要兽人的孩子]{.lookup-name} [+6 GP]{.gp-in}

继续听完文治和斗次郎的讨论，登记「[梦见与兽人孩子的未来](../collectibles/achievements.md#a1991){.achievement-ref}」。这是 D35 [文治](d35.md#bunji-child-prerequisites)和[斗次郎](d35.md#tojiro-child-prerequisites)两条孩子路线的共用前置。
:::

::: {#not-so-interested-in-children .choice-row data-lookup="倒也没那么想要 #1991 #3491 #3492 成就已放弃 孩子约定"}
[没那么想要]{.lookup-name} [+4 GP]{.gp-in}

若已有「[梦见与兽人孩子的未来](../collectibles/achievements.md#a1991){.achievement-ref}」，会提示该成就「丢弃了」。D35 会跳过孩子问句。保持同一位伴侣时，已有孩子约定仍会让新生活接到孩子结局。想改回普通结局，先补回上面的「我也想要兽人的孩子」，再回 D35「尾声」选「放弃孩子」。[完整步骤](d35.md#change-child-decision)
:::
:::

## [午休]{.lookup-name} {#lunch data-lookup="从午休开始 自由午休 狸丸 大门前 番外 狸丸的秘密"}

[打开 D20 午休地图](d20-lunch.md)。「从午休开始」直接进地图。休息处和事务所也有生育话题的选项，D35 的孩子前置在[午休前的便当段](#before-lunch)登记。

狸丸的指定拜访在 [D16 大门前](d16-lunch.md#gate)之后接 [D24 大门前](d24-lunch.md#gate)。D20 的六处午休可按想看的对话或所需 GP 来选。

## [下午]{.lookup-name} {#afternoon data-lookup="从下午工作开始 从下午作业开始 文治 敲伤手指 斑 狮子堂 供品 保密 #1992"}

时间线选「从下午工作开始」。主角敲伤手指，文治过来查看。

### 让我看看。 {#check-injured-hand}

::: {.choice-list data-place="下午 · 加工场"}
::: {#show-injured-hand .choice-row data-lookup="伸出手"}
[把手给他看]{.lookup-name} [+4 GP]{.gp-in}

给文治看伤处。他让主角去事务所处理。
:::

::: {#make-a-joke-about-the-injury .choice-row data-lookup="亮出性器"}
[把性器给他看]{.lookup-name} [−4 GP]{.gp-out}

文治喝止，叫主角把手伸出来。付费增加一小段对白，之后照常去事务所。
:::
:::

::: {#overheard-offices .event-record data-lookup="事务所 社长室 斑 斑点 狮子堂 雪之丞 自动视角 供品 兽神祭"}
[事务所与社长室的对话]{.lookup-name}

主角去处理手伤时听见斑和社长谈供品，叙事会自动切进社长室，再回到主角。两种查看手伤的答法都会到这里，随后斑询问能否保密。
:::

### 能保密吧？ {#keep-the-secret}

::: {.choice-list data-place="下午 · 事务所"}
::: {#keep-secret .choice-row data-lookup="保守秘密 #1992 成就已放弃 D28 狩猎"}
[保密]{.lookup-name} [+4 GP]{.gp-in}

答应斑保密。若已有「[无法保守秘密的主人公](../collectibles/achievements.md#a1992){.achievement-ref}」，这次会提示成就「丢弃了」，同时关掉 [D28 祭典的狩猎邀约](d28.md#hunt-invitation)。
:::

::: {#tell-everyone .choice-row data-lookup="告诉大家 #1992 供品 D23 D28 D34"}
[跟大家说]{.lookup-name} [+6 GP]{.gp-in}

斑先劝主角别说，读完这段对白会登记「[无法保守秘密的主人公](../collectibles/achievements.md#a1992){.achievement-ref}」。主角回去会把听见的事告诉文治，[D28 祭典](d28.md#hunt-invitation)上斑会邀请他打猎，第一次拒绝后还会再问一次。
:::
:::

<details id="secret-follow-up" class="kt-read-more" data-lookup="#1992 无法保守秘密的主人公 跟大家说 保密 D23 D28 D34 猎杀 邀约 那种守不住秘密的主人公">
<summary>保密选择的后续 · D20 收工、D23、D28、D34</summary>

- **D20 收工。** 持有这项成就时，主角会跟熊手问起狮子堂建设的旧事。开启「剧情缩短」也会保留这段对话。
- **[D23 社长面谈](d23.md#president-after-meeting)。** 成就会触发面谈后斑与社长的一段对话。
- **D28 兽神祭。** 持有时会遇到[斑的狩猎邀约](d28.md#hunt-invitation)。想继续参加祭典，要连续选两次「拒绝」。任一次选「帮忙打猎」都会触发同一个 Game Over，含死亡情节。确认后可在第一次邀约重选。祭典后还有几处对白会读这项成就。
- **[D34 旅馆](d34.md#shishidou-asks-about-forgiveness)。** 和狮子堂、斑同行时，会多听到一段解释狩猎邀约的对白。两种情况都会接到「能原谅／不能原谅」，80 GP 的「不能原谅」可单独补。

回补或撤掉这项前置，用时间线选「从下午工作开始」，走到「能保密吧？」再改选。两项的 GP 各领一次。

</details>
