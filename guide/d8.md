## [上午]{.lookup-name} {#morning data-lookup="从上午工作开始 从上午作业开始 斑 布知 雪之丞 员工旅行"}

时间线选「从下午工作开始」。先和雪之丞说话，再去社长室。

### 被社长叫，是不是干了坏事？ {#called-by-president}

::: {.choice-list data-place="下午"}
::: {#did-something-bad .choice-row data-lookup="做了坏事"}
[干了坏事]{.lookup-name} [+6 GP]{.gp-in}

主角编了个玩笑，雪之丞让他先去见社长。
:::

::: {#did-nothing-bad .choice-row data-lookup="没做坏事"}

主角说没做坏事，雪之丞鼓励他去见社长。
:::
:::

两项都接社长面谈。**接下来的「继续干」会出现割手和血液画面。**

### 社长劝主角主动辞职 {#employment-decision data-lookup="你一身上的理由辞了，我可轻松。怎样？ 要是你这小鬼能因为自己的原因主动辞职，那我可是帮了大忙了。怎么选？"}

::: {.choice-list data-place="下午 · 社长面谈"}
::: {#keep-working .choice-row data-lookup="继续工作"}
[继续干]{.lookup-name} [+4 GP]{.gp-in}

坚持继续工作，进入[兽人的誓言](#oath)，随后正常收工。
:::

::: {#resign .choice-row data-lookup="辞去工作 #792 辞去工作 正しい選択 正确的选择 坏结局"}
[辞职]{.lookup-name} [+6 GP]{.gp-in}

主角签字离职，出现 Game Over「正确选择」。继续确认会登记成就「[因个人原因辞去了兼职](../collectibles/achievements.md#a792){.achievement-ref}」，再回到同一题。改选「继续干」即可继续，辞职成就会保留。
:::
:::

::: {#oath .event-record data-lookup="兽人的誓言 兽人之誓 社长 狮子堂 割手 血液 CG 立誓"}

选「继续干」后，主角与社长立下誓言，过程中会自动出现手掌受伤和血液画面。社长当场认可主角为正式员工，D9 的剧情接着这段誓言。补这段从「从下午工作开始」进入。
:::

## [收工]{.lookup-name} {#work-end data-lookup="收工 回程 超市 从下午工作开始"}
