## [回跳改选]{.lookup-name} {#change-companion data-lookup="丢弃了 成就已放弃 撤销 前置 换伴侣 改结局 入职 #3390 #3391 #3392 #3491 #3492"}

D35 用的是**当前伴侣**。从 D34「从选择开始」改选时，选完同行人后读到撤销提示，会先撤掉相斥的关系。到[回家](#home)或[D35「尾声」](d35.md#epilogue)时，游戏直接读取改后的状态。

| 改选位置 | 会撤掉的当前状态 |
| --- | --- |
| 同行菜单选文治 | 斗次郎、熊手的伴侣状态。撤掉斗次郎伴侣时，同时撤掉他的孩子约定 |
| 同行菜单选斗次郎 | 文治、熊手的伴侣状态。撤掉文治伴侣时，同时撤掉他的孩子约定 |
| 同行菜单选熊手 | 文治、斗次郎的伴侣状态及随对应关系撤掉的孩子约定。已有的熊手伴侣继续生效 |
| 同行菜单选雪之丞，或选狮子堂和斑 | 三人的伴侣状态。撤掉文治或斗次郎伴侣时，也会撤掉该人的孩子约定 |
| 文治或斗次郎的伴侣题选「先想想」或「拒绝」 | 撤掉这位角色的伴侣状态，保留他的孩子约定。之后再单独换同行人，旧约定仍会保留 |
| 熊手温泉后的正式确认选「拒绝」 | 只撤掉熊手伴侣状态。此前的「想跟其中一人结成伴侣」和「跟两人都不想」会保留旧关系 |

已收的片尾成就、已开的图库、买过的选项和各日期的前置成就都会保留。看到「丢弃了」，可以从提示里确认这次撤掉的是哪段关系或哪个约定。想重开后沿用这次改选，可返回时间线，点右上角的保存图标，看到「已保存游玩数据」再退出。

要补[入职](d35.md#employment)，可以随雪之丞走，在进店那题选「跟雪之丞进店」。走狮子堂和斑的路线时，午饭选「什么都行」，饭后选「能原谅」。已有孩子约定、想补同一人的普通共同生活，按 [D35 的改选办法](d35.md#change-child-decision)走。
