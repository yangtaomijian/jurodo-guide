### 这样浇混凝土会怎样？ {#concrete-pressure}

::: {.choice-list data-place="下午"}
::: {#say-explosion .choice-row data-lookup=""}
[会爆炸]{.lookup-name} [+4 GP]{.gp-in}

文治说离正确答案不远，接着解释混凝土会把模板撑歪。
:::

::: {#say-world-ends .choice-row data-lookup="世界会毁灭"}
[世界毁灭]{.lookup-name} [+4 GP]{.gp-in}

文治吐槽，又解释模板承受的压力。
:::

::: {#unsure-about-concrete .choice-row data-lookup=""}
[不知道]{.lookup-name} [+4 GP]{.gp-in}

文治直接讲没有对拉时会发生什么。三项都接角紧的讲解。
:::
:::

### 文治讲解链条为何要控制在 45 度以内 {#chain-angle data-lookup="超过45度拉力会散掉。懂吗？ 要是不控制在45度以内，链条受到的拉力就会被分散掉。能明白吗？"}

::: {.choice-list data-place="下午"}
::: {#understand-angle .choice-row data-lookup="明白"}
[懂]{.lookup-name} [+4 GP]{.gp-in}

:::
