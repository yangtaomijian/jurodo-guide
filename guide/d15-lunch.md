时间线选「从午休开始」。地点奖在收尾发，和选项的 GP 分开算。

## [现场下层]{.lookup-name} {#site-lower data-lookup="工地下层 偏右下 斗次郎 睡觉 #1491 CG 图库"}

偏右下 · 斗次郎 · 地点奖 **+8 GP**

::: {#tojiro-asleep .event-record data-lookup="斗次郎睡姿 插图 CG"}
[斗次郎睡姿插图]{.lookup-name}

进地点就会出现。选「让他睡，离开」也能看到。后续付费场景含未经同意的接触。
:::

### 斗次郎在现场睡着 {#sleeping-tojiro}

::: {.choice-list data-place="现场下层"}
::: {#leave-tojiro-asleep .choice-row data-lookup="让斗次郎继续睡，悄悄离开"}
[让他睡，离开]{.lookup-name} [+4 GP]{.gp-in}

悄悄离开，让斗次郎继续睡。独自度过午休后也能领地点奖。
:::

::: {#tojiro-sleeping-scene .choice-row data-lookup="把斗次郎的肉棒插进屁穴里 #1491 插进了在工地睡觉的斗次郎的肉棒 CG 图库"}
[把斗次郎的性器插进后穴]{.lookup-name} [−80 GP]{.gp-out}

进入成人 CG。读到成就「[插入了在现场睡觉的斗次郎的鸡巴](../collectibles/achievements.md#a1491){.achievement-ref}」登记可开放[图库回放](../collectibles/gallery.md#replay-d15-tojiro){.gallery-ref}。继续读过斗次郎醒来的视角，才领地点奖。
:::
:::

## [值班室]{.lookup-name} {#guardroom data-lookup="工棚 左下 文治 图纸 桌子下 #1492"}

左下 · 文治 · 地点奖 **+8 GP**

### 文治在看图纸 {#bunji-studies-plans}

::: {.choice-list data-place="值班室"}
::: {#stay-quiet-with-bunji .choice-row data-lookup="为了不打扰文治而保持安静"}
[安静别打扰他]{.lookup-name} [+4 GP]{.gp-in}

主角先在旁边等，文治后来主动聊起他的暑假。读完领地点奖。
:::

::: {#distract-bunji .choice-row data-lookup="吮吸文治的性器打扰他 #1492 在休息室的桌子底下悄悄让文治射了 CG 图库"}
[含他性器去打扰]{.lookup-name} [−64 GP]{.gp-out}

进入桌下的成人场景。读到成就「[在值班室桌子下偷偷让文治射精](../collectibles/achievements.md#a1492){.achievement-ref}」登记可开放[图库回放](../collectibles/gallery.md#replay-d15-bunji){.gallery-ref}，再继续读到收尾领地点奖。
:::
:::

## [大门前]{.lookup-name} {#gate data-lookup="最右侧 狸丸 狸丸的秘密 #1456 兽神 祭品 番外前置"}

最右侧 · 狸丸

::: {.event-record}
狸丸在场时会谈到兽神和祭品。把对话读到他离开，会自动登记「狸丸的秘密」的一项前置并得 **+8 GP**。如果狸丸已经离开，这里是空地点，0 GP，随后回地图。
:::

## 选完后怎么补 {#revisit}

- 有人地点读到收尾会接下午工作，空地点会回地图。可从[时间线的「从午休开始」](../mechanics/timeline.md#back-to-d15)回补。
- 解锁[「无限午休功能」](../mechanics/gp.md#features)后，读完地点也能回地图继续选，结束时点右侧箭头。
