时间线选「从午休开始」。有人地点各给 **+8 GP**，读到收尾到账，和选项的 GP 分开算。

## [现场上层]{.lookup-name} {#site-upper data-lookup="工地上层 斗次郎 拥抱 接吻 强吻 CG 图库 #991"}

中央偏上 · 斗次郎 · 地点奖 **+8 GP**

**接吻分支含强吻情节。**

### 斗次郎问怎么拉近关系 {#tojiro-break data-lookup="……好处，具体干什么。 ……你说搞好关系，到底要怎么搞？"}

::: {.choice-list data-place="现场上层"}
::: {#hug-tojiro .choice-row data-lookup="和斗次郎亲密地拥抱"}
[跟斗次郎抱抱]{.lookup-name} [+6 GP]{.gp-in}

主角抱住斗次郎，斗次郎很快挣开。读完领地点奖。
:::

::: {#kiss-tojiro .choice-row data-lookup="和斗次郎亲密地接吻 #991 在工地现场和斗次郎接了吻"}
[跟斗次郎接吻]{.lookup-name} [−24 GP]{.gp-out}

出现接吻 CG，场景中登记成就「[在现场与斗次郎接吻](../collectibles/achievements.md#a991){.achievement-ref}」，并解锁[图库回放](../collectibles/gallery.md#replay-d10-tojiro){.gallery-ref}。接着读到离开，再领地点奖。
:::
:::

## [现场下层]{.lookup-name} {#site-lower data-lookup="工地下层 文治 实况 攻略 剧透 游戏"}

偏右下 · 文治 · 地点奖 **+8 GP**

### ……你也看实况？ {#game-streams}

::: {.choice-list data-place="现场下层"}
::: {#watch-streams .choice-row data-lookup=""}
[看]{.lookup-name} [+4 GP]{.gp-in}

文治聊到实况和剧透，对整段公开剧情的实况有意见。
:::

::: {#skip-streams .choice-row data-lookup=""}
[不看]{.lookup-name} [+4 GP]{.gp-in}

文治聊自己遇到卡关时怎么处理，两人说到睡一觉再回来玩。
:::
:::

### ……你喜欢游戏吗？ {#game-taste}

::: {.choice-list data-place="现场下层"}
::: {#likes-games .choice-row data-lookup=""}
[喜欢]{.lookup-name} [+4 GP]{.gp-in}

文治让主角珍惜自己喜欢游戏的心情。
:::

::: {#games-are-okay .choice-row data-lookup="也就那样吧"}
[一般]{.lookup-name} [+4 GP]{.gp-in}

主角说自己更看重角色，两人聊游戏口味。
:::
:::

第一问两项都会接第二问，读完第二问的对话后发地点奖。

## [大门前]{.lookup-name} {#gate data-lookup="最右侧 狸丸 狸丸的秘密 #956 番外前置"}

最右侧 · 狸丸

狸丸在场时，主角和他聊岛上与本土的区别，话题转到黄油。读完自动登记「狸丸的秘密」的一项前置，并得 **+8 GP**。如果狸丸已经离开，点这里会看到空地点，0 GP，随后回地图。

## 选完后怎么补 {#revisit}

- 有人地点读完会接下午工作。要换地点或补另一项，从[时间线的「从午休开始」](../mechanics/timeline.md#back-to-d10)再进。
- 解锁[「无限午休功能」](../mechanics/gp.md#features)后，读完可回地图继续选，结束时点右侧箭头。已登记的成就和图库回放会保留。
