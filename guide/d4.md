## [起床与出勤]{.lookup-name} {#wakeup data-lookup="从起床开始 下雨 朝会 晨会"}

时间线选「从起床开始」。下雨照常上工，朝会改在值班室。

### 下雨也要起床 {#get-up}

::: {.choice-list data-place="起床"}
::: {#rise .choice-row data-lookup="起床 下雨"}
[起来]{.lookup-name} [+4 GP]{.gp-in}

起床准备出门，文治提醒还是带把伞。
:::

::: {#stay-in-bed .choice-row data-lookup="不起床 下雨"}
[不起]{.lookup-name} [+6 GP]{.gp-in}

主角不想淋雨。听说今天没有室外的活，还是起床了。
:::
:::

### 被这么血气方刚的兽人围着没事？ {#breakfast}

在值班室吃早饭时，北野门左卫门问主角适不适应。两项都接朝会。

::: {.choice-list data-place="早饭"}
::: {#used-to-it .choice-row data-lookup="北野门左卫门 北野门"}
[已经习惯了]{.lookup-name} [+4 GP]{.gp-in}

话题转到兽人会不会吃人。
:::

::: {#excited .choice-row data-lookup="很兴奋 北野门左卫门 北野门"}
[会兴奋]{.lookup-name} [+6 GP]{.gp-in}

主角说自己反而会兴奋，北野门左卫门顺着话开玩笑。
:::
:::

## [上午]{.lookup-name} {#morning data-lookup="从上午工作开始 从上午作业开始 对拉杆 放线"}

时间线选「从上午工作开始」。

::: {#snap-ties .event-record data-lookup="掰对拉杆 锤子 插图 CG 熊手"}
[掰对拉杆的插图]{.lookup-name}

熊手用锤子示范怎么掰掉露在墙外的对拉杆。演示图在文治的问答前自动出现，开启「剧情缩短」也会经过这里。
:::

### 精密仪器，别乱碰。 {#layout-tool}

关闭「剧情缩短」时，会看到文治提醒主角别乱碰放线器。

::: {.choice-list data-place="上午工作"}
::: {#leave-tool-alone .choice-row data-lookup="我会小心不乱碰的 文治 放线器"}
[注意不碰]{.lookup-name} [+4 GP]{.gp-in}

答应注意，继续听文治讲放线。
:::

::: {#touch-bunji .choice-row data-lookup="摸摸文治的裆部 文治 放线器"}
[摸文治的裆]{.lookup-name} [−4 GP]{.gp-out}

被文治训了一句，随后继续工作。
:::
:::

::: {#mark-wall .event-record data-lookup="放线 弹墨 墨斗 文治 插图 CG 剧情缩短"}
[弹墨放线的插图]{.lookup-name}

两项之后都会看到文治拉线弹墨。开启「剧情缩短」会跳过放线器的问答和这组插图。
:::

### 所以，人类有事？ {#call-tojiro}

午饭前，主角去叫还在收拾的斗次郎。两项都接着去买便当。

::: {.choice-list data-place="午休前"}
::: {#call-for-lunch .choice-row data-lookup="来叫你去吃午饭 斗次郎 便当"}
[来叫午饭]{.lookup-name} [+4 GP]{.gp-in}

照常叫斗次郎吃饭。
:::

::: {#joke-tojiro .choice-row data-lookup="来舔你的鸡巴 斗次郎 便当"}
[来舔鸡巴]{.lookup-name} [−12 GP]{.gp-out}

斗次郎追问是不是真的，主角说是开玩笑。接着照常买便当，这里只有对白差异。
:::
:::

### 怎样，摸摸看？ {#kitanomon}

买便当回值班室后，北野门左卫门提出邀请。这一问在午休地图之前，回补要选「从上午工作开始」。

::: {.choice-list data-place="午休前 · 值班室"}
::: {#touch-kitanomon .choice-row data-lookup="抚摸 摸了北野门的裆部 触摸了北野门左卫门的股间 #391"}
[摸]{.lookup-name} [−8 GP]{.gp-out}

继续读可得成就「[触摸了北野门左卫门的股间](../collectibles/achievements.md#a391){.achievement-ref}」。
:::

::: {#kitanomon-gallery .choice-row data-lookup="口交 给北野门口交了 含住了北野门左卫门的鸡巴 #392 CG 图库 标题页立绘"}
[舔]{.lookup-name} [−24 GP]{.gp-out}

有成人 CG。读完可得成就「[含住了北野门左卫门的鸡巴](../collectibles/achievements.md#a392){.achievement-ref}」，同时开放[图库回放](../collectibles/gallery.md#replay-d4-guardroom){.gallery-ref}。这也是解锁北野门左卫门标题立绘的三项条件之一。
:::

::: {#decline-kitanomon .choice-row data-lookup="北野门左卫门 北野门 拒绝"}
[什么都不做]{.lookup-name} [+4 GP]{.gp-in}

主角婉拒，接回值班室闲聊。三项之后都能进入午休地图。
:::
:::

::: {#no-girlfriend .choice-row data-lookup="熊手 女朋友"}
