## [起床与出勤]{.lookup-name} {#wakeup data-lookup="从起床开始 早操 广播体操"}

时间线选「从起床开始」。现场暂时没活，今天改到公司加工。出工前，斗次郎解释做操是为了活动身体。开启「剧情缩短」会跳过这道问答。

### 斗次郎问你怎么看开工前的热身操 {#warm-up data-lookup="……你以为我们在无意义地做操？ ……喂，你以为这体操是随便做着玩的吗？"}

::: {#explain-warm-up .choice-row data-lookup="没那回事 斗次郎 早操"}

主角问大家为什么做得这么认真，斗次郎说明热身能防止受伤。
:::

::: {#joke-warm-up .choice-row data-lookup="我还以为有什么色色的含义 斗次郎 早操"}

## [上午]{.lookup-name} {#morning data-lookup="从上午工作开始 从上午作业开始 加工场 加工单"}

时间线选「从上午工作开始」。开启「剧情缩短」会跳过文治演示前的问答、加工过程，以及去便利店认路的问答。上午收尾仍会出现手伤插图。

### ── 听好了，现在讲加工，看好。 {#watch-bunji}

::: {.choice-list data-place="上午工作 · 加工场"}
::: {#watch-hands .choice-row data-lookup="注视文治的手头 手边 模板 加工"}
[看文治的手边]{.lookup-name} [+4 GP]{.gp-in}

看文治操作，学习加工步骤。
:::

::: {#look-at-bunji .choice-row data-lookup="注视文治的胯下 模板 加工"}
[看文治的胯下]{.lookup-name} [−4 GP]{.gp-out}

文治提醒主角认真。两项都接到加工演示。
:::
:::

::: {#fabrication-illustrations .event-record data-lookup="加工单 模板 锤子 PP带 扎带 打包 血泡 手指 受伤 插图 CG"}
[加工演示与手伤插图](../collectibles/gallery.md#cg-d5-injury){.lookup-name .gallery-ref}

文治展示「加工单」，示范组装和捆扎模板。主角用锤子砸到手指时会自动出现手伤特写，继续工作后还会再看到一次。后一次出现在上午收尾，开启「剧情缩短」也会看到。
:::

### 路记住了吧？ {#remember-route}

斗次郎领主角走到便利店。两项都接主角买便当。

::: {.choice-list data-place="午休前 · 便利店"}
::: {#know-route .choice-row data-lookup="记住了路 斗次郎 便利店 便当"}
[记住路了]{.lookup-name} [+4 GP]{.gp-in}

主角说记住了，斗次郎让他照旧买午饭。
:::

::: {#joke-route .choice-row data-lookup="记住了斗次郎的屁股形状 便利店 便当"}
[记住了斗次郎屁股的形状]{.lookup-name} [−4 GP]{.gp-out}

斗次郎对这个回答发火，催主角去买饭。
:::
:::

### 斗次郎问你和兽人待在一起会不会害怕 {#tojiro-question data-lookup="跟我们这种货待在一起，你没事吗！？ 你跟我们这种家伙待在一起，真的能安得下心吗！？"}

买便当回来后，斗次郎问主角怕不怕。三项都接午饭，随后可以自由行动。

::: {.choice-list data-place="午休前"}
::: {#feel-safe .choice-row data-lookup="不害怕 斗次郎 被吃"}
[没事]{.lookup-name} [+4 GP]{.gp-in}

主角说大家待他很好，斗次郎还是用吃人的话吓他。
:::

::: {#feel-afraid .choice-row data-lookup="斗次郎 害怕 被吃"}
[害怕]{.lookup-name} [+4 GP]{.gp-in}

主角承认害怕，但还是想做这份工作。斗次郎的反应和上一项相同。
:::

::: {#shock-tojiro .choice-row data-lookup="想被你强暴 斗次郎 被吃"}
[想被侵犯]{.lookup-name} [−4 GP]{.gp-out}

主角把话题扯到性，斗次郎接了几句后，大家照常吃饭。这项只有对白差异。
:::
:::
