## [起床]{.lookup-name} {#wakeup data-lookup="从起床开始 文治 冷战 #2691 #2693 对文治彻底死心"}

时间线选「从起床开始」。两道沉默选项都在出门前。

### 起床后见到文治 {#greet-bunji}

::: {.choice-list data-place="起床 · 第一问"}
::: {#greet-bunji-as-usual .choice-row data-lookup="向文治打招呼"}
[跟文治打招呼]{.lookup-name} [+4 GP]{.gp-in}

主动打招呼。若已有「[对文治感到厌烦](../collectibles/achievements.md#a2691){.achievement-ref}」，会撤掉它，连带撤掉已有的「[拒绝了文治](../collectibles/achievements.md#a2693){.achievement-ref}」。
:::

::: {#stay-silent-at-first .choice-row data-lookup="什么也不说"}
[什么都不说]{.lookup-name} [+6 GP]{.gp-in}

文治也沉默。接下来还有一问，要连续沉默两次才会登记「[对文治感到厌烦](../collectibles/achievements.md#a2691){.achievement-ref}」。
:::
:::

### 要不要开口安抚文治 {#reassure-bunji}

::: {.choice-list data-place="起床 · 第二问"}
::: {#reassure-bunji-as-usual .choice-row data-lookup="顾及文治的感受"}
[顾着文治]{.lookup-name} [+4 GP]{.gp-in}

告诉文治会照常相处。若已有「[对文治感到厌烦](../collectibles/achievements.md#a2691){.achievement-ref}」，会撤掉它，连带撤掉已有的「[拒绝了文治](../collectibles/achievements.md#a2693){.achievement-ref}」。
:::

::: {#stay-silent-again .choice-row data-lookup="什么也不说"}
[什么都不说]{.lookup-name} [+6 GP]{.gp-in}

若第一问也选了「什么都不说」，此时登记[「对文治感到厌烦」](../collectibles/achievements.md#a2691){.achievement-ref}。
:::
:::

::: {#fed-up-with-bunji .event-record data-lookup="#2691 对文治彻底死心 拒绝文治 什么也不说"}
[对文治感到厌烦](../collectibles/achievements.md#a2691){.achievement-ref .lookup-name}

起床连续沉默后自动登记，决定上午文治提出接吻时会出现哪组答案。要走拒绝线，到了上午还要选「还在意」把这个状态留到下一问。
:::

## [朝会]{.lookup-name} {#morning-meeting data-lookup="朝礼 安全朝会 熊手 你也别那么蔫"}

从起床继续读。熊手会按主角目前和文治的关系多问几句，最后让他照常相处。直接从「从上午工作开始」会跳过这题。

### 你也别那么蔫，照常处就行。 {#kumade-advice}

::: {.choice-list data-place="朝会 · 熊手"}
::: {#agree-with-kumade .choice-row data-lookup="好的"}
[是]{.lookup-name} [+4 GP]{.gp-in}

答应照常相处，随后开工。
:::

::: {#disagree-with-kumade .choice-row data-lookup="不要"}
[不是]{.lookup-name} [+6 GP]{.gp-in}

熊手说主角也很固执，让他闹到消气。接同样的上午工作，两项都不改变后面的接吻菜单。
:::
:::

## [上午]{.lookup-name} {#morning data-lookup="从上午工作开始 从上午作业开始 梁底 拔钉 文治 和好 #2692"}

时间线选「从上午工作开始」。开着「剧情缩短」会跳过下面递梁底的问答，之后的施工插图和文治的关键问答仍会出现。

### 往上递梁底 {#pass-beam-boards}

::: {.choice-list data-place="上午 · 拆模"}
::: {#call-bunji .choice-row data-lookup="和文治搭话 招呼文治"}
[叫文治]{.lookup-name} [+4 GP]{.gp-in}

主角先招呼文治接梁底。此前有没有对文治感到厌烦，会改变对话的语气。
:::

::: {#stay-silent-at-work .choice-row data-lookup="什么也不说"}
[什么都不说]{.lookup-name} [+6 GP]{.gp-in}

文治先开口。两人照常递梁底，这次沉默不改变起床写下的状态。
:::
:::

::: {#removing-slab-cg .event-record data-lookup="斗次郎 主角 楼板 梁底 拆模 CG 插图"}
[拆楼板模板的施工插图]{.lookup-name}

斗次郎示范、主角跟着操作、楼板落下的画面随上午工作自动出现。看完继续到拔钉。
:::

### ……还在意吗？ {#still-bothered}

::: {.choice-list data-place="上午 · 拔钉"}
::: {#let-it-go .choice-row data-lookup="已经不在意了 #2691 #2693 丢弃了 成就已放弃"}
[已经不在意]{.lookup-name} [+4 GP]{.gp-in}

若有「[对文治感到厌烦](../collectibles/achievements.md#a2691){.achievement-ref}」，就撤掉它，连带撤掉已有的「[拒绝了文治](../collectibles/achievements.md#a2693){.achievement-ref}」。下一问会出现「和文治接吻」。
:::

::: {#still-bothered-answer .choice-row data-lookup="还是有点介意"}
[还在意]{.lookup-name} [+6 GP]{.gp-in}

主角说还有点在意，文治道歉。若起床已登记「[对文治感到厌烦](../collectibles/achievements.md#a2691){.achievement-ref}」，会把它保留到下一问。原先没有这项成就时，这里也不会补上。
:::
:::

**「拒绝文治」会在午休前进入正式片尾。** 要继续到 D28，可选「和文治接吻」或「什么都不做」。

### 文治提出接吻 · 当前没有「对文治感到厌烦」 {#kiss-or-do-nothing}

::: {.choice-list data-place="上午 · 接吻邀约"}
::: {#kiss-bunji .choice-row data-lookup="#2692 和文治交换了约定的吻"}
[和文治接吻]{.lookup-name} [+6 GP]{.gp-in}

自动出现和好之吻的 CG，继续读到通知，登记[「与文治做了约定的吻」](../collectibles/achievements.md#a2692){.achievement-ref}并开放同名图库。照常进午休。
:::

::: {#do-nothing-after-making-up .choice-row data-lookup="什么也不做 #2692 #2693 丢弃了 成就已放弃"}
[什么都不做]{.lookup-name} [+4 GP]{.gp-in}

略过吻 CG，撤掉已持有的「[与文治做了约定的吻](../collectibles/achievements.md#a2692){.achievement-ref}」和「[拒绝了文治](../collectibles/achievements.md#a2693){.achievement-ref}」，照常进午休。
:::
:::

### 文治提出接吻 · 当前有「对文治感到厌烦」 {#reject-or-do-nothing}

::: {.choice-list data-place="上午 · 接吻邀约"}
::: {#do-nothing-while-upset .choice-row data-lookup="什么也不做 #2692 #2693 丢弃了 成就已放弃"}
[什么都不做]{.lookup-name} [+4 GP]{.gp-in}

略过吻 CG，撤掉已持有的「[与文治做了约定的吻](../collectibles/achievements.md#a2692){.achievement-ref}」和「[拒绝了文治](../collectibles/achievements.md#a2693){.achievement-ref}」，保留「[对文治感到厌烦](../collectibles/achievements.md#a2691){.achievement-ref}」，照常进午休。两组「什么都不做」共用这笔 +4 GP。
:::

::: {#reject-bunji .choice-row data-lookup="#2693 #2694 失恋的尽头"}
[拒绝文治]{.lookup-name} [+6 GP]{.gp-in}

撤掉已持有的「[与文治做了约定的吻](../collectibles/achievements.md#a2692){.achievement-ref}」，登记「[拒绝了文治](../collectibles/achievements.md#a2693){.achievement-ref}」，继续读到午饭后会[自动进提前片尾](#early-ending)。
:::
:::

::: {#promise-kiss .event-record data-lookup="#2692 #4965 和文治交换了约定的吻 接吻 CG 图库 D28 牵手 供物"}
[与文治做了约定的吻](../collectibles/achievements.md#a2692){.achievement-ref .lookup-name}

接吻后继续读完对话。成就当前生效时，[D28 跟文治一起](d28.md#bunji-route)会在牵手后多出一吻，接下来才按供物状态分流。改选「什么都不做」或「拒绝文治」会撤掉这一前置，已开放的吻回放仍可进入。要给 D28 补回前置，可从上午重走「已经不在意」→「和文治接吻」，也可读完[图库回放](../collectibles/gallery.md#replay-d27-promise-kiss){.gallery-ref}。
:::

图库从拔钉时的谈话起播，自动走「已经不在意」和「和文治接吻」。读到重新登记成就后会返回图库。回到时间线手动保存，可保留恢复的前置。

## [午休前]{.lookup-name} {#before-lunch data-lookup="多谢款待 失恋的尽头 目击了文治与监督的性爱 #2693 #2694"}

午饭后，游戏检查「[拒绝了文治](../collectibles/achievements.md#a2693){.achievement-ref}」。这项成就当前生效时，主角会去找文治并自动进提前片尾。走其他两项则直接进午休地图。

<summary><span class="lookup-name">失恋的尽头</span> · 成人 CG · 正式片尾</summary>

::: {.day-route-content}

::: {#witness-bunji-and-supervisor .event-record data-lookup="#2694 撞见文治和监督在做爱 文治 监督 事务所 片尾 监督标题立绘"}
[目击了文治与监督的性爱](../collectibles/achievements.md#a2694){.achievement-ref .lookup-name}

上午选「拒绝文治」后继续。狸丸在场会指路，到事务所时自动出现成人 CG。确认「失恋的尽头」后登记成就，再播正式片尾。第一次看完正式片尾可取得「[因果的紊乱](../collectibles/achievements.md#a4011){.achievement-ref}」，并在功能解锁画面购买时间线。改选后这项成就和[图库回放](../collectibles/gallery.md#replay-d27-early-ending){.gallery-ref}仍会保留。图库播到事务所的后续对白就返回。

已解锁北野门左卫门的标题立绘时，拿到这项成就就满足监督立绘的条件。[D13 厕所的成就](d13-lunch.md#restroom)也会计 1 点，可以留到之后补。
:::

D27 未走完过正常收尾时，时间线只有「从起床开始」和「从上午工作开始」。要继续到 D28，从上午选「已经不在意」清掉拒绝状态，再选「和文治接吻」或「什么都不做」，接着把 D27 读完。当日结算后会开放另外三个时段。

:::

</details>
