## 开场设置 {#setup}

### [你对这款游戏有何期待？]{.lookup-name} {#preference data-lookup="开场偏好 游戏目的 游玩目的 GP 开场奖励"}

这个选择决定**开场奖励**和 **D1–D34 正常收尾时的日结奖励**。开场拿到的 GP 可以直接用在面试里。

::: {.gp-budget data-place="开场设置"}
| 游戏选项 | 开场／每次日结（各） | 领齐奖励可得 | 全买后预算余额 |
| --- | ---: | ---: | ---: |
| [作为游戏的娱乐]{#game-purpose .lookup-name data-lookup="开场偏好 作为游戏的娱乐性 作为游戏的娱乐体验"} | 0 | 3,850 | **28** |
| [作为读物的故事]{#story-purpose .lookup-name data-lookup="阅读剧情 作为读物的故事情节 作为阅读物的剧情故事"} | +12 | 4,270 | **448** |
| [作为性处理的工具]{#third-purpose .lookup-name data-lookup="作为性处理的道具 第三项 作为发泄欲望的工具"} | +25 | 4,725 | **903** |
:::

表内单位是 GP。收入按领齐开场奖、34 笔正常日结、选项奖和午休奖计算。全买共花 **3,822 GP**，包含番外和 D14 的进店选项。

第三项全程比第一项多 **875 GP**，比第二项多 **455 GP**。「剧情缩短」选「不使用」也照发。第一项的预算余额为 **28 GP**，补收时可在时间线右下角查当前 GP。[预算明细和日结例外](../mechanics/gp.md#d1-bonus)

::: {.choice-list data-place="开场设置"}
::: {#violence-setting .choice-row data-lookup="残酷描写 表现修正 加强残酷描写的修正 不加强 遮挡 开启强力遮挡（减少刺激画面） 轻度遮挡（保持原汁原味）"}

选「加强残酷描写的修正」或「不加强」。之后可在「设定」中调整。

选「设为残像」「设为效果线」或「设为无」。这会改变部分演出画面，之后也可在「设定」中调整。
:::

::: {#shortening .choice-row data-lookup="剧情缩短 剧情缩减 使用 不使用"}
[剧情缩短]{.lookup-name}

开场只有选「作为性处理的工具」才会看到「使用」「不使用」。D1 开启后会跳过午休末尾「有问题吗？」的整组问答，也会略过部分对白和洗澡演出。要补被跳过的选项，先在「设定」关闭，再用时间线回到对应时段。
:::
:::

完成设置后会自动保存，随后进入 D1。

### 晚饭吃不吃咔咔粮 {#dinner}

### 夜里 {#night}

::: {#jerky .event-record data-lookup="文治送肉干 从文治那里得到了肉干 从文治那儿收到了肉干 没有吃卡里卡里 没吃干粮 #92"}
[文治送肉干]{.lookup-name}

熄灯后，持有「[没有吃卡里卡里](../collectibles/achievements.md#a91){.achievement-ref}」才会自动触发。把对话读完可得成就「[从文治那里得到了肉干](../collectibles/achievements.md#a92){.achievement-ref}」。洗澡顺序任选。回补时在时间线选「从回家开始」，晚饭选「不勉强吃」并继续到夜里。
:::

### [当天结算]{.lookup-name} {#day-reward data-lookup="首次推进奖励 GP 作为读物的故事 作为性处理的工具"}

首次推进到 D1 收尾时，「作为读物的故事」另得 **+12 GP**，「作为性处理的工具」另得 **+25 GP**。「作为游戏的娱乐」没有这笔奖励。晚饭两种选法都能走到结算，重走 D1 不会重复发放。
