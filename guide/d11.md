## [起床与出勤]{.lookup-name} {#wakeup data-lookup="从起床开始 劲敌 斗次郎 晨跑 跑步 朝会"}

时间线选「从起床开始」。天还没亮，斗次郎喊主角出门跑步。

### 斗次郎喊你一起晨跑 {#running-invitation data-lookup="醒太早了，跑步。你也陪着。 我醒得太早了，去跑步。你也给我一起。"}

::: {.choice-list data-place="起床"}
::: {#run-with-tojiro .choice-row data-lookup=""}
[陪他跑步]{.lookup-name} [+4 GP]{.gp-in}

陪斗次郎跑步，接到[途中问答](#tojiro-goal)。
:::

::: {#suggest-something-else .choice-row data-lookup="陪他打飞机"}
[陪他自慰]{.lookup-name} [−4 GP]{.gp-out}

斗次郎拒绝这个提议，还是带主角跑步，照常接到[途中问答](#tojiro-goal)。
:::

::: {#decline-running .choice-row data-lookup=""}
[拒绝]{.lookup-name} [+6 GP]{.gp-in}

主角拒绝陪跑，跳过跑步和途中问答，直接接到出勤。
:::
:::

### 你……在嘲讽我？ {#tojiro-goal}

::: {.choice-list data-place="起床 · 跑步"}
::: {#tease-tojiro .choice-row data-lookup="在小看你"}
[在嘲讽]{.lookup-name} [+6 GP]{.gp-in}

主角直说觉得斗次郎可爱，斗次郎追问原因。
:::

::: {#deny-teasing .choice-row data-lookup="没有小看你"}
[没有嘲讽]{.lookup-name} [+4 GP]{.gp-in}

主角说没有嘲讽，斗次郎还是觉得被取笑。两项都在出勤前结束跑步。
:::
:::

## [上午]{.lookup-name} {#morning data-lookup="从上午工作开始 从上午作业开始 斗次郎 回墙 拼缝 模板"}

时间线选「从上午工作开始」。完整剧情中，斗次郎示范立回墙，会自动出现记号、插对拉和打钉的施工插图。「剧情缩短」会一并略过两道施工问答和这组插图。文治和斗次郎争论由谁教拆楼板，熊手安排文治来教。

::: {#wall-2-1-right .choice-row data-lookup=""}
[墙2-1右]{.lookup-name} [+4 GP]{.gp-in}

答对，斗次郎让主角去找这块模板。
:::

::: {#unknown-wall .choice-row data-lookup=""}
[不知道]{.lookup-name} [+4 GP]{.gp-in}

斗次郎报出「墙2-1右」，让主角去找。
:::

::: {#snap-at-tojiro .choice-row data-lookup=""}
[发火]{.lookup-name} [+6 GP]{.gp-in}

主角用斗次郎平时的口气回嘴，斗次郎还是报出编号。之后都找同一块模板。
:::
:::

## [午休前]{.lookup-name} {#before-lunch data-lookup="从上午工作开始 文治 斗次郎 熊手 拆楼板"}

从「从上午工作开始」推进到这里。完整剧情中，斗次郎再次要求由他来拆楼板。文治问他是不是想教主角。随后开启午休地图。「剧情缩短」会直接进入午休地图。

## 午休 {#lunch data-lookup="从午休开始 自由午休 插图 狸丸 番外前置 #1056"}

[打开 D11 午休地图](d11-lunch.md)。七处都只有固定剧情。要补[隔墙插图](d11-lunch.md#wall-joint)，去现场上层。要补[狸丸的拜访记录](d11-lunch.md#gate)，趁他还在时去大门前。

## [下午与收工]{.lookup-name} {#afternoon data-lookup="从下午工作开始 从下午作业开始 拆楼板 撑杆 施工 CG"}

时间线选「从下午工作开始」。文治示范扔撑杆拆楼板，自动出现施工插图，然后才会问主角感想。「剧情缩短」仍会播这段示范和问答，随后略过主角试扔的那段演出。

### ……喂，怎么了？ {#slab-demonstration}

::: {.choice-list data-place="下午"}
::: {#impressed-by-demo .choice-row data-lookup="太震撼了"}
[太厉害了]{.lookup-name} [+4 GP]{.gp-in}

主角问起有噪声限制时怎么拆，文治解释另一种做法。
:::

::: {#off-topic-reaction .choice-row data-lookup="看硬了"}
[勃起了]{.lookup-name} [−4 GP]{.gp-out}

主角答非所问，文治把话题拉回施工。随后照常拆楼板。
:::
:::

接着还有拆胶合板的插图，完整剧情也会看到拔钉。收工时文治和斗次郎因现场安全吵起来，接着回家。

## [回家]{.lookup-name} {#home data-lookup="从回家开始 寿喜烧 晚饭 熊手 抽烟 烟呛到了"}

时间线选「从回家开始」。完整剧情中，晚饭会自动出现寿喜烧插图。「剧情缩短」略过吃饭，仍会走到烟味问答。
