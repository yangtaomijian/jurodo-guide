## [起床]{.lookup-name} {#wakeup data-lookup="从起床开始 文治 午饭 烤肉 剧情缩短"}

时间线选「从起床开始」。关闭「剧情缩短」时，起床后会看到这道问答，随后大家吃文治做的午饭，自动出现餐食插图，再选择同行人。

### 文治问你是不是累坏了 {#rested data-lookup="你是不是累积太多了？ 你小子，是不是累坏了啊？"}

::: {.choice-list data-place="起床"}
::: {#slept-well .choice-row data-lookup="睡饱了，精神得很 文治"}
[睡够了所以很精神]{.lookup-name} [+4 GP]{.gp-in}

主角说自己睡足了，文治放心。

::: {#still-tired .choice-row data-lookup="只有裆下精神得很 文治"}
[只有胯下很精神]{.lookup-name} [+6 GP]{.gp-in}

主角说疲劳还没消，话题转到人和兽人的身体。
:::
:::

## [选同行人]{.lookup-name} {#companion data-lookup="从选择开始 从选项开始 今天和谁一起度过 同行路线"}

时间线选「从选择开始」可直达。这一选只决定当天去处。三条路线都接回家，成就可分开回补。

::: {.choice-list data-place="选同行人"}
::: {#with-bunji .choice-row data-lookup="和文治一起度过 选文治"}
[和文治过]{.lookup-name} [+4 GP]{.gp-in}

[文治 · 在社宅打游戏](#bunji)。游戏画面自动出现，另有 40 GP 的成就和图库场景。
:::

::: {#with-tojiro .choice-row data-lookup="和斗次郎一起度过 选斗次郎"}
[和斗次郎过]{.lookup-name} [+4 GP]{.gp-in}

[斗次郎 · 去海边](#tojiro)。冲浪图自动出现，另有 40 GP 的成就和图库场景。
:::

::: {#with-kumade .choice-row data-lookup="和熊手一起度过 选熊手"}
[和熊手过]{.lookup-name} [+4 GP]{.gp-in}

[熊手 · 去河边](#kumade)。两道付费选项共 48 GP，可收两项成就，其中一项是后续前置。
:::
:::

<details id="kumade" class="kt-read-more day-route" data-lookup="熊手 高潮树 伊库伊库之树 欢愉树 伴侣前置 D34">
<summary><span class="lookup-name">熊手</span> · 两项成就、后续前置</summary>

::: {.day-route-content}
要补熊手的后续前置，走「和熊手过」→「好」或「不好」→「插入高潮树」→「劝熊手也射」。两道付费题先扣 **16 GP**，后扣 **32 GP**。两项都没买时，若同行和邀约的奖励也都可领，从同行菜单带 **40 GP**（答「好」）或 **38 GP**（答「不好」）就够。两笔奖励都领过时，需要带 **48 GP**。

::: {#decline-kumade .choice-row data-lookup="不了 熊手 河边"}
[不好]{.lookup-name} [+6 GP]{.gp-in}

## [回家]{.lookup-name} {#home data-lookup="从回家开始 晚饭 烤鸡串 酒"}

三条同行路线在回家汇合。时间线可选「从回家开始」直接补晚饭时的问答。桌上烤鸡串的插图在选项前出现。

::: {.choice-list data-place="回家"}
::: {#accept-drink .choice-row data-lookup="斗次郎 喝酒"}
[喝酒]{.lookup-name} [+4 GP]{.gp-in}

主角答应，文治提醒他才十八岁。
:::

::: {#refuse-drink .choice-row data-lookup="斗次郎 不喝酒"}
[拒绝]{.lookup-name} [+4 GP]{.gp-in}
