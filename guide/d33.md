晚餐三道菜都吃，会进[聊恋爱](#talk-about-love)。至少一次选「拒绝」，会登记「[没能吃完怀石料理](../collectibles/achievements.md#a3291){.achievement-ref}」，接[调饮料](#make-drink)和独立图库。两条都可以从「从晚餐开始」补。

## [起床]{.lookup-name} {#wakeup data-lookup="从起床开始 员工旅行 集合 雪之丞"}

时间线选「从起床开始」。斗次郎叫主角起床，几人去集合，等雪之丞来开车。

## [出发]{.lookup-name} {#departure data-lookup="从出发开始 巴士 中巴 员工旅行"}

时间线选「从出发开始」。众人坐中巴出发。途中停车休息，最后开过贴近悬崖的山路。

## [到达]{.lookup-name} {#arrival data-lookup="从到达开始 从抵达开始 抵达 温泉旅馆 鹤之间"}

时间线选「从到达开始」。到旅馆后，众人找房间、安顿行李。主角随后跟文治、斗次郎出去转转。

## [观光]{.lookup-name} {#sightseeing data-lookup="从观光开始 温泉 土产 旅馆 散步"}

时间线选「从观光开始」。几人先去看温泉，再在旅馆里转一圈，回房后接泡温泉。

## [温泉]{.lookup-name} {#hot-spring data-lookup="从温泉开始 雪之丞 文治 斗次郎 16 GP"}

时间线选「从温泉开始」。泡到后半段，雪之丞会起哄问要不要碰文治和斗次郎。**付费项含成人情节。**

### 酱怎样。想握两人的鸡巴吧？ {#hot-spring-invitation}

::: {.choice-list data-place="温泉 · 雪之丞"}
::: {#accept-hot-spring-invitation .choice-row data-lookup="想摸文治和斗次郎的肉棒"}
[想握文治和斗次郎的鸡巴]{.lookup-name} [−16 GP]{.gp-out}

接到众人起哄的段落。花费解锁这段立绘和对白，随后照常吃晚餐。
:::

::: {#decline-hot-spring-invitation .choice-row data-lookup=""}
[还是算了]{.lookup-name} [+4 GP]{.gp-in}

主角婉拒，雪之丞作罢。继续泡温泉，再接晚餐。
:::
:::

## [晚餐]{.lookup-name} {#dinner data-lookup="从晚餐开始 怀石料理 蝾螺 毛豆 吃搞不懂的东西 #3291 扣工资 CG"}

时间线选「从晚餐开始」。怀石料理插图随上菜自动出现。三道题都会问完。想进[聊恋爱](#talk-about-love)，三道都选吃。想进[调饮料](#make-drink)，任一道选「拒绝」即可。

### 这贝真好吃。尝尝。 {#taste-turban-shell}

::: {.choice-list data-place="晚餐 · 第一道"}
::: {#eat-turban-shell .choice-row data-lookup=""}

吃下这道，接着问毛豆。
:::

::: {#refuse-turban-shell .choice-row data-lookup=""}
[拒绝]{.lookup-name} [+6 GP]{.gp-in}

留下这道，饭后会走调饮料。毛豆和下一道仍可以选。

留下毛豆，饭后会走调饮料。下一道仍可以选。

### 最后一道小菜要不要尝？ {#taste-the-last-dish data-lookup="这个搞不懂的也好吃！吃吃！ 君，这个搞不懂的也好吃！吃吃！ ，这个不知名的小菜也很好吃哦！快尝尝快尝尝！"}

::: {.choice-list data-place="晚餐 · 第三道"}

[吃搞不懂的东西]{.lookup-name} [+4 GP]{.gp-in}

吃下最后一道。前两道也都吃了，才会进聊恋爱。

::: {#refuse-the-last-dish .choice-row data-lookup=""}
[拒绝]{.lookup-name} [+6 GP]{.gp-in}

留下这道，饭后会走调饮料。

::: {#unfinished-kaiseki .event-record data-lookup="#3291 没能吃完怀石料理 丢弃了 成就已放弃 调饮料 聊恋爱"}
[没能吃完怀石料理](../collectibles/achievements.md#a3291){.achievement-ref .lookup-name}

至少拒绝一道，饭后就会登记这项成就并用它进入调饮料。回到「从晚餐开始」把三道都吃掉，会提示这项成就「丢弃了」，随后改进聊恋爱。此前取得的调饮料及「喝／不喝」成就和图库仍会保留。再进调饮料的图库回放，读到饭后分流时会恢复这项成就。要清掉它，从时间线把三道菜都吃完。
:::

## [晚餐后]{.lookup-name} {#after-dinner data-lookup="聊恋爱 调饮料 扣工资 GP 成就 图库 #3292 #3293 #3294 #3295"}

::: {#talk-about-love .event-record data-lookup="#3292 和公司的大家聊了恋爱话题 与公司的大家聊了恋爱话题 三道都吃"}
[与公司的大家聊了恋爱话题](../collectibles/achievements.md#a3292){.achievement-ref .lookup-name}

三道都吃就进这段。把众人聊恋爱的剧情读到深夜，自动登记成就。之后可正常结算。
:::

<summary>调饮料 · 含成人情节 · 可收三项成就和图库</summary>

::: {.day-route-content}

至少拒绝一道菜，接到饭后调饮料。剧情会提到减薪，实际 GP 只按选项和日结增减。

::: {#drink-replay .event-record data-lookup="#3293 和公司的大家一起制作了精液特饮 与公司的大家制作了精液饮料 图库 角色立绘"}
[与公司的大家制作了精液饮料](../collectibles/achievements.md#a3293){.achievement-ref .lookup-name}

调好后会自动登记，早于「喝／不喝」。[图库回放](../collectibles/gallery.md#replay-d33-drink){.gallery-ref}从晚餐开场起播，跳过三道菜的问答并进入调饮料，仍可选「喝／不喝」并看到对应收尾。整段用角色立绘演出。
:::

### ── 怎样。喝，还是不喝？ {#drink-or-refuse}

::: {.choice-list data-place="晚餐后 · 调饮料"}
::: {#drink-it .choice-row data-lookup="#3294 喝下了大家做的精液特饮"}
[喝]{.lookup-name} [+6 GP]{.gp-in}

主角喝下，读到通知会登记「[喝下了大家的精液饮料](../collectibles/achievements.md#a3294){.achievement-ref}」。随后正常结算。
:::

::: {#let-buchi-drink .choice-row data-lookup="#3295 让斑喝下了精液特饮"}
[不喝]{.lookup-name} [+4 GP]{.gp-in}

主角拒绝，最后由斑喝下，登记「[让斑喝了精液饮料](../collectibles/achievements.md#a3295){.achievement-ref}」。随后正常结算。
:::
:::

要把两个结果都登记，可以从图库重播，末尾选另一项。首次可领该选项的 GP 并登记成就。回到图库后退出到时间线，点右上角保存。

:::
